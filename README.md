# NanoDx Website

Mobile first, investor focused redesign of nanodiagnostics.com.

Single file site: open `index.html` in any browser. No build step.

## Host on GitHub Pages
Settings → Pages → Source: Deploy from a branch → `main` / root → Save.

## Before going public
Confirm sign off on the investor market figures (TAM / SAM / SOM) and the 510(k) wording.
